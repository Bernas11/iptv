# Repositório IPTV

Este repositório está **sem playlists publicadas** na branch `main`. O objetivo histórico era organizar listas no formato M3U; não há atualmente uma lista ativa para descarregar ou usar.

## Estado e âmbito

- Não são fornecidos streams, canais, guias EPG, logótipos ou credenciais.
- O formato M3U, por si só, não concede direitos sobre o conteúdo transmitido nem autorização para redistribuir um URL.
- A remoção de ficheiros da branch principal não apaga necessariamente versões antigas do histórico Git; não reutilizes URLs históricos sem nova verificação e autorização.

## Condições para aceitar uma futura entrada

Uma contribuição com uma fonte só poderá ser considerada quando incluir, por cada entrada:

1. A identidade do titular/operador e a página oficial da fonte.
2. Prova verificável de autorização de acesso e, quando aplicável, de redistribuição pública.
3. A licença ou termos aplicáveis, território permitido e data da última verificação.
4. Um contacto ou procedimento de remoção para o titular dos direitos.

Só serão consideradas fontes oficialmente autorizadas. Não submetas listas encontradas na Internet sem prova de permissão, streams de acesso pago, conteúdo protegido sem autorização, credenciais, tokens, endereços privados ou URLs temporários/assinados.

## Propor uma alteração

Abre uma [issue](https://github.com/Bernas11/iptv/issues) com a documentação de proveniência **sem incluir o URL do stream**. Se a permissão não puder ser confirmada publicamente, a entrada não será aceite. Não testamos nem reproduzimos streams submetidos.

## Licença

Este repositório não declara uma licença para playlists ou conteúdos de terceiros. A ausência de uma licença não concede permissão de redistribuição. Uma licença do código ou da documentação não abrangeria automaticamente os direitos sobre streams, marcas ou guias de programação.
